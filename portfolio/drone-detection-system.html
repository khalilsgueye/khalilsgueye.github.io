Drone Detection System

Khalil Gueye

A system built to receive, interpret, and display the Remote ID signals broadcast by drones flying nearby.

Overview

This is a drone detection system built to receive, interpret, and then display Remote ID (RID) signals emitted by drones flying nearby. The FAA requires all drones above 250 g to broadcast Remote ID. However, some custom-made, illegal, or government drones may not emit it, and those won’t be picked up by this detector.

Drones emit RID over Wi-Fi or Bluetooth. The ESP32-S3 has both Wi-Fi and Bluetooth receivers, so it’s capable of detecting these signals. There is Mesh Mapper firmware for a XIAO chip available on GitHub. We don’t use a XIAO chip, but ours is similar, so it’s a good starting point. The XIAO firmware has the useful logic for the detection process, but lacks the configuration we need, such as how the app starts and how memory is organized. We take that firmware, modify it for our use case, and flash it onto our ESP32.

Firmware

The ESP32’s Wi-Fi and Bluetooth receivers are built to listen for signals at 2.4 GHz and turn them into bits according to the two standards. Once a signal is received and demodulated, it’s filtered against certain criteria to check whether it has the characteristics of a Remote ID. If it does, the ID is turned into a text object and sent over the USB port.

Python

We built a Python program that runs persistently and displays the RID in the terminal. It listens on the USB port for messages passed by the ESP32, and when it receives an RID object, it displays it in the terminal.

Future Iterations

We can make this system more versatile and powerful by having the ESP32 pass its text objects to a Meshtastic radio chip and broadcast them over LoRa to a receiver. This would let us set up multiple nodes and potentially triangulate the location of drones that don’t already broadcast their coordinates. We would have the program listen over Wi-Fi, or set up a listening device connected over USB. We could then display the results on a webpage or another more useful medium.
