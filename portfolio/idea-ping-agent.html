Idea Ping Agent

A simple web form lets you jot down an idea, pick a future date, and give an email address to send it to. Behind the scenes, an agent quietly summarizes your idea with a local AI and delivers it back to you by email on the date you chose — like a message to your future self, but smarter.

Local LLM SQLite Scheduled Jobs SMTP Email Web Form

How it works

The agent is built as a small pipeline: capture an idea, let it sit, enrich it with a local model, and deliver it on schedule.

01

Idea capture

A web page presents a form with three fields: the destination email address, the idea itself (a reminder, a thought worth revisiting, anything), and a date to send it.

02

Ingestion

On submit, the form data is saved into a database as a raw, unprocessed idea record.

03

Periodic scan

Every 30 minutes, a scheduled job reads through the database looking for newly submitted ideas that haven't been processed yet.

04

Local LLM processing

Each new idea is sent to a local LLM running on the machine, which is prompted to summarize the idea and give feedback on it. The result is saved as a new object into a second database — an outbox of ready-to-send emails.

05

Scheduled dispatch

Every hour, a separate job checks the outbox for anything whose specified send date has arrived. If it finds a match, it sends the processed idea — summary and feedback included — to the destination email address.

Why split into two databases and two schedules

Capturing, processing, and sending are decoupled on purpose. The 30-minute scan handles enrichment independently of the hourly dispatch check, so a slow or busy LLM pass never delays email delivery, and a delivery run never has to wait on processing to finish.

Applied uses

This agent demonstrates a delayed, AI-enriched message-to-self pattern: capture a thought now, let a model add value to it, and deliver it on a future date.

  • Personal idea incubation. Send yourself a fleeting idea today and receive it back later with a summary and honest feedback, at a point when you're ready to actually evaluate it.
  • Future reminders with context. Instead of a bare reminder, the recipient gets an AI-processed version of the original note, making it easier to act on.
  • Delayed journaling. Thoughts logged in the moment are returned on a chosen date, turned into something more reflective than the raw entry.
  • Follow-up nudges for tasks. An open task or question can be dropped in and resurfaced automatically, summarized, on the date it needs attention.

The reusable core is the split between fast capture, asynchronous enrichment via a local model, and independent scheduled delivery — a pattern that applies anywhere content needs to be gathered now but processed and released later.
